# 🏋️‍♂️ FitJourney — Workout & Macro Tracker

**FitJourney** is a React Native application that helps users plan and monitor their fitness journey.  
Track your workouts, log your daily macros (calories, protein, carbs, fats), and visualize your progress — all in one clean, intuitive mobile app.

---

## 📱 Features

### 🏃‍♀️ Workout Tracking
- Create, edit, and delete workout routines.
- Log exercises with sets, reps, and weights.
- View workout history and performance trends.

### 🍎 Macro Tracking
- Track daily calorie and macronutrient intake.
- Add and manage meals or custom food items.
- Automatic macro goal calculation based on user profile.

### 📊 Progress & Insights
- Visual progress charts for strength and nutrition.
- Weekly summaries and goal adherence.
